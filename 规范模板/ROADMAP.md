# 项目工程路线图

## 要求

- 基于`dev-guide.md`生成
- 可追朔需求
- 步骤按照严格的开发逻辑顺序
- 先写单元测试，后写代码，最后集成测试

## 格式

```markdown
# xxx 项目工程路线图

## M0 项目骨架

## M1 xxx

- 实现需求：BR- · FR-
- 目标：

### Step 1-1 xxx

- 涉及文件：所有在本步骤中创建/编辑的文件
- 实现 BR-*
- 实现 FR-*
- 总结精华/设计巧思（50 词内）

- [ ] 操作
	- [ ] xxx 自行总结
- [ ] 测试
    - [ ] xxx 自行总结
- [ ] 验收
	- [ ] xxx 自行总结
	- [ ] 本步骤各文件单元测试覆盖率是否超过 80%，核心功能是否 100% 覆盖
	- [ ] 本步骤全部产出物符合预期功能需求
	- [ ] 本步骤符合预期性能需求
	- [ ] 本步骤产出物命名合规
	- [ ] 本步骤产出物位置合规
- [ ] 提交
    - [ ] 生成 commit 建议，形如 git commit -m "前缀(范围): 中文简述"
  
### Step 1-2 xxx

## M2 xxx

```
