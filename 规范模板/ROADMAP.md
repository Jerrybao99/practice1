# 项目工程路线图

## 要求

- 可追朔需求
- 步骤按照严格的开发逻辑顺序
- 先写单元测试，后写代码，最后集成测试

## 格式

```markdown
# xxx 项目工程路线图

## M0 项目骨架

## M1 xxx

### Step 1-1 xxx

- 涉及文件：所有在本步骤中创建/编辑的文件
- 实现需求：

- [ ] 操作
	- [ ] xxx 自行总结
- [ ] 测试
  - [ ] xxx 自行总结
- [ ] 验收
	- [ ] xxx 自行总结
- [ ] 提交
  - [ ] 生成 commit 建议，形如 git commit -m "前缀(范围): 中文简述"
  
### Step 1-2 xxx

## M2 xxx

```
