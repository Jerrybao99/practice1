# 快速开始

## 文档须知

- 提供给软件开发新人**快速、实用、复用、唯一**的项目学习入口

## 交互示例

> 建议不批量操作，确保 AI 注意力集中且效率足够  

prompt 1：透视仓库知识结构，按如下步骤顺序严格执行：
1. 目标仓库：提示我输入要分析的仓库的路径，并阅读其全部文件
2. 项目透视模板：提示我输入项目透视模板的路径；并严格参考该模板提供的要求以输出项目透视
3. 输出仓库的项目透视文件`目标仓库名-quick-view.md`于指定路径中：提示我输入目标路径

> 注入上下文  
> 拖拽 目标文件/文件夹 到 zed AI 交互界面中  

prompt 2：从工作日志（journal）中整理工作意图（intention），按如下步骤顺序严格执行：
1. 日志文件夹：提示我输入要分析的日志文件夹的路径，并阅读其全部文件
2. 工作意图文件夹：提示我输入要分析的工作意图文件夹的路径，并阅读其全部文件
3. 代码仓库：提示我输入要分析的代码仓库的路径，并阅读其全部文件
4. 工作意图模板：提示我输入工作意图模板的路径，并严格参考该模板提供的要求以输出工作意图
5. 输出工作意图文件`代码仓库名-intention.md`于指定路径中：提示我输入目标路径

prompt 3：从工作语境（context）中整理工作洞察（insight），按如下步骤顺序严格执行：
1. 工作语境文件：提示我输入要分析的工作语境文件的路径，并阅读其全部文件
2. 工作洞察模板：提示我输入工作洞察模板的路径；并严格参考该模板提供的要求以输出工作洞察
3. 输出工作洞察文件`工作语境文件名-insight.md`于指定路径中：提示我输入目标路径
