# 工作洞察模板

- [ ] 不超过 80 行
- [ ] 用词专业且言简意赅
- [ ] 采用问题驱动型叙事框架，每个标题间承担独立功能，并形成认知递进闭环
- [ ] 原文的转写，并不凭空创造
  - [ ] 全文出现的所有专有名词（工具名、流程名、角色名、项目名）必须可以在工作语境文档中逐字找到
  - [ ] 所有输出的观点和内容必须能在原文中找到对应的原文段落或论点，不得为了框架完整而凭空补充原文没有的逻辑环节。若原文缺少某层所需素材，宁可缺层或缩并为一句过渡，也不编造
- [ ] 本文所有的复选框、有序列表、表格内容不出现在输出中，仅为 AI 生成的约束条件

## 情景导入

- [ ] 用读者亲身经历的具体困境开场，以第二人称制造代入感，将抽象议题转化为"你"的问题，让读者先"看见"问题，再"理解"概念

## 核心概念

- [ ] 迅速抛出一个简洁模型或公式，锚定全文核心讨论边界，降低认知负荷
- [ ] 公式加粗，另起一行突出

## 分层递进

- [ ] 按维度或假设将问题剖开，每个子问题遵循"假设 → 矛盾 → 解法"的三段式，像剥洋葱一样，逐层揭示更复杂的现实
- [ ] 落笔前须先穷举原文中所有"假设/矛盾"对，确定实际子问题数量，避免遗漏
- [ ] 格式范例：

```markdown

### xxx

**假设**：

**矛盾**：

**解法**：

```

## 价值升华

- [ ] 在解决表面问题的解法之后，再补一刀，超出基本解法，揭示更深层的增值视角

## 总结收束

- [ ] 一句话概括核心挑战与核心价值，形成闭环记忆点
