# Agent Instructions

## 定位

本章程是量潮数据工程的**治理规则**，回答"必须做什么"的问题。

它与 specification（规范）的关系：

| 维度 | **bylaw（章程）** | **spec（规范）** |
|---|---|---|
| 角色 | 规则与治理 | 结构与格式 |
| 回答 | 必须做什么 | 长什么样 |
| 违反后果 | 流程不合规 | 工具解析失败 |

bylaw 定义流程要求、质量约束、变更规则、跨领域边界。

spec 定义目录结构、文件格式、字段定义、命名约定。

**bylaw 和 spec 不重复，各自回答不同层面问题。**
